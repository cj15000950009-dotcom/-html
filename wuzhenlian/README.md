# 武侦连纪律锁 · 视觉小说前端

本仓库是「魔鬼鱼超级前端」为角色卡 **《武侦连纪律锁_20260813》** 重配的版本：一个基于 React + Vite 的视觉小说前端，支持立绘、背景、CG、剧情选项、时间卡、战术地图、世界书、存档等，可独立运行，也可嵌入 SillyTavern（酒馆）作为角色卡前端。

## 角色卡

- 角色卡文件：`F:\ai收纳库\skills\武侦连纪律锁_20260813.json`（chara_card_v3，含 68 条世界书词条）
- 前端内置了该卡的 43 条世界书词条（角色/事件/规则）作为独立运行时的世界观上下文

## 两种运行方式

### 方式一：独立网页运行（需要 Gemini API Key）

1. 安装依赖：`npm install`
2. 在 `.env.local` 中设置 `GEMINI_API_KEY`（或启动后在「系统设置」里填 API Key）
3. 启动：`npm run dev`，浏览器打开 http://localhost:3000
4. 构建：`npm run build`（产物在 `dist/`）

**直接打开静态页（无需任何服务器）**：构建完成后，直接双击 `dist/index.html` 即可在浏览器中运行。
产物已针对 file:// 协议优化：资源全部相对路径引用、JS 打包为普通脚本（IIFE）而非 ES module（避免 file:// 下 CORS 拦截）、CSS 与字体均已内联/相对引用。
把整个 `dist/` 文件夹复制到任意位置或上传到任意静态托管（GitHub Pages、Nginx、对象存储等）同样可用。

独立运行不依赖酒馆，由前端直接调用 Gemini 生成剧情（世界书内容来自 `constants.ts` 内嵌词条；未配置 API Key 时界面仍可打开，在「系统设置」中填入即可）。

### 方式二：嵌入 SillyTavern（酒馆）作为角色卡前端（推荐）

1. 在酒馆中导入角色卡 `武侦连纪律锁_20260813.json`（角色 + 其世界书自动随卡导入）。
2. **重要**：为了让模型按前端可解析的「<VN><maintext> 管道符格式」输出（驱动立绘/背景/选项），请用本目录的合并世界书替换角色卡自带的默认世界书：
   - 在角色卡编辑 → 世界书中，将默认世界书替换为 `武侦连纪律锁_世界书_含前端格式.json`
   - 该文件 = 角色卡 68 条原词条 + 前端输出格式规则 4 条（72 条）
3. 在酒馆消息楼层中通过加载器注入本前端（构建产物或开发服务器地址），前端通过酒馆助手 API（`getChatMessages` / `generate` 等）读写楼层、驱动画面。

## 与「罗天虎」原版的差异

- 角色替换为武侦连 10 人：孙卫东、高猛、罗振海、秦铮、贺国栋、林正平、邵凯、孟凯、马强、方啸 + 主角（钥匙官）
- 世界观改为磐石营区·合成一营·武装侦察连·纪律锁制度
- 世界书词条改为角色卡 43 条有效词条（含「雄性凝视法则」「游玩/回复规则」「钥匙官职责」「纪律锁制度」等）
- 开场改为《新兵下连 · 接任钥匙官》与《锁务室交接》
- 背景库改为磐石营区地点（训练场/宿舍/连部/锁务室/澡堂/食堂/器械场/厕所/军械库/营部/家属楼/仓库/岗哨/跑道/靶场）
- CG 库清空（本卡暂无 CG 素材，可在图库中自行导入）
- 战术地图改为磐石营区布局
- 修复了原版的独立构建问题：补齐 `index.html` 入口、`zod`/`lodash`/`tailwindcss` 依赖、字体资源路径

## 目录说明

- `constants.ts`：角色、世界观、开场、背景、立绘库、世界书、战术地图等全部数据（角色卡专用）
- `武侦连纪律锁_世界书_含前端格式.json`：酒馆可导入的合并世界书
- `App.tsx` / `components/`：视觉小说引擎（立绘舞台、对话框、选项、存档、图库、地图、设置等）
- `services/`：Gemini 直连与酒馆 generate 两种生成通道
- `utils/messageParser.ts`：解析 `<VN><maintext>` 管道符正文、选项、立绘/背景/CG 指令
