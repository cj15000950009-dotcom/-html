# 水墨江湖 · 对话框素材

本目录图片从仓库外层的 `dist/皮肤-水墨江湖/` 中拣选复制，供 `ink-jianghu` 主题使用。

| 文件 | 用途 |
|------|------|
| `paper_texture.png` | 对话框宣纸底纹（`ink-jianghu-dialogue-surface`） |
| `mountain_wash.png` | 极淡山水晕染层（`::before`，multiply 混合） |
| `seal_orbit.png` | 右下角墨圈点缀（`::after`） |

更换风格时：可替换同名 PNG，或改 [`styles/global.css`](../styles/global.css) 中的 `url(...)` 指向新文件。
